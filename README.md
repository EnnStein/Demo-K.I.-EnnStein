# Demo-K.I.-EnnStein
This is an older project, which shows some problems of AIs. The UI is in german.

Dieses Projekt wurde in einer Schule verwendet, um Schwachstellen von K.I.s zu verdeutlichen.
Man kann sehr leicht den Zusammenhang von den eingegebenen Daten mit dem Ergebnis erkennen:
Fehler in der Eingabe => Fehler in der Ausgabe
Keine Information => keine (qualifizierte) Antwort
